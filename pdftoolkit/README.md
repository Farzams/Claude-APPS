# PDF Toolkit

Split, merge, compress, convert (EPUB, MOBI, FB2, DjVu, XPS, CBZ, HTML, TXT, DOCX…), images to PDF, page tools and OCR.

The Windows build bundles **DjVuLibre** (`ddjvu`, GPL-2.0, https://djvu.sourceforge.net) so DjVu conversion works with no extra install. It is run as a separate program, unmodified.
Optional extras: Tesseract (OCR), Ghostscript (stronger compression), Calibre (DOCX/AZW3/RTF).
